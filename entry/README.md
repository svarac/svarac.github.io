# 出演者さま提出ページ（/entry/）

- 公開用：`/entry/`（クイズ案提出・ボイメ提出）
- 管理用：`/entry/admin/`（パスワード制）

受け取ったデータは Google Apps Script 経由で、運営の Google スプレッドシート「SVARAC 提出管理」と
Google ドライブ「SVARAC 提出音源」に保存されます。このリポジトリには入りません。

受け皿のURLは `config.js` の `api` に入れます。

## ジングル応募（/jingle/）

- 公開用：`/jingle/`（「スバラシー！」シャウト・5秒インパクト・アイコンの応募。その場で録音もできます）
- 管理用：`/entry/admin/#jingle`（同じパスワード。ステータス・使った回・メモ・ZIPダウンロード・受付のオン／オフ）

受け皿は同じ Google Apps Script（ファイル「jingle.gs」）。応募はスプレッドシート「SVARAC ジングル応募」、
音源とアイコンはドライブ「SVARAC ジングル音源」（スバラシー／5秒／アイコン）に入ります。
管理ページで「採用」にした人は、トップページの「ジングル」欄に採用した順で並びます（受付中はコンテンツ欄に募集カードが出ます）。
